# JuliaHub (Julia Computing)

> JuliaHub, Inc. (founded 2015 as Julia Computing by the creators of the Julia programming language) develops the open-source Julia language and operates JuliaHub, a cloud platform for scientific and technical computing: hosted Julia compute, package hosting and the Julia package registry, notebooks, and large-scale batch/job execution. Programmatic access is provided through the first-party JuliaHub.jl Julia client, authenticated with OpenID Connect (Dex). This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public surface.

## Products
- [Julia](https://juliahub.com/products/julia): The open-source Julia programming language.
- [JuliaHub](https://juliahub.com/products/juliahub): Cloud platform for Julia compute, packages, notebooks, and jobs.
- [Dyad](https://juliahub.com/products/dyad): Equation-based modeling and simulation.
- [Pumas](https://juliahub.com/products/pumas): Pharmaceutical modeling and simulation.

## Programmatic access / SDK
- [JuliaHub.jl](https://help.juliahub.com/juliahub-jl/stable/): Official Julia client for the JuliaHub platform (jobs, datasets, auth).
- [JuliaHub.jl getting started](https://help.juliahub.com/juliahub-jl/stable/getting-started/)
- [PkgAuthentication.jl](https://github.com/JuliaComputing/PkgAuthentication.jl): Authenticate a Julia depot against a JuliaHub package server.
- [GitHub organization](https://github.com/JuliaComputing)

## Authentication
- [OpenID Connect discovery](https://juliahub.com/.well-known/openid-configuration): Dex issuer https://auth.juliahub.com/dex; authorization_code, device_code, refresh_token and token-exchange grants; PKCE (S256); scopes openid/email/profile/groups/offline_access.
